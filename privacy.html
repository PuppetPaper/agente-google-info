Política de privacidad

Integración personal «agente» · NEXUS en Hermes Agent

Versión preparada el 15 de octubre de 2026.

1. Ámbito y contacto

Esta política describe la configuración personal de «agente», utilizada por Saul para conectar su propia cuenta de Google a NEXUS. No describe todas las instalaciones de Hermes ni constituye una política oficial de Google, Nous Research u otro proveedor.

Contacto del titular: saulmoy@gmail.com. No se ofrece acceso público a esta integración.

2. Datos y finalidades

Según la petición del titular y los permisos concedidos, la integración puede acceder a mensajes y metadatos de Gmail, archivos y metadatos de Drive, eventos de Calendar, contenido de Docs y Sheets y contactos de Google. Puede tratar adjuntos si la tarea exige acceder a ellos.

El acceso se destina a buscar, consultar, resumir, redactar, organizar y ejecutar acciones solicitadas. Contactos utiliza acceso de solo lectura. Los permisos de los demás servicios incluyen capacidades de escritura; la configuración operativa requiere confirmar envíos, compartición, modificaciones y eliminaciones.

No se vende la información de Google ni se utiliza esta integración para publicidad o para crear un servicio de datos para terceros.

3. Procesamiento con IA y destinatarios

Las herramientas locales realizan las solicitudes a las API de Google. Si una tarea requiere interpretación o generación con IA, el contenido recuperado que sea necesario puede enviarse a los proveedores de modelos configurados en Hermes. En la configuración documentada para esta integración se utilizan OpenAI mediante Codex y NaN para determinadas rutas, auxiliares o respaldos; las rutas pueden cambiar con la configuración del titular.

No se garantiza procesamiento exclusivamente local. Los proveedores pueden tratar datos fuera del país del titular conforme a las condiciones y controles aplicables a su cuenta. Esta política no acredita por sí sola sus ubicaciones, plazos de conservación ni la exclusión de entrenamiento; esas condiciones deben consultarse con cada proveedor. Si no resultan aceptables para un dato, el titular no debe solicitar su envío al modelo ni ejecutar una tarea que lo requiera.

Una solicitud autorizada de envío de correo o de compartición puede comunicar datos a los destinatarios elegidos. La existencia de acceso a Google no autoriza por sí sola otras publicaciones o transferencias.

4. Credenciales y almacenamiento

La conexión utiliza OAuth: la contraseña de Google no se almacena en los archivos de esta integración. El cliente OAuth y el token de acceso y renovación se guardan en el perfil local de Hermes del PC del titular.

En la configuración comprobada, los permisos de Windows de esos archivos están restringidos al usuario del titular y a SYSTEM. Son archivos JSON y no se ha incorporado cifrado mediante la bóveda de Hermes. Esa protección no impide el acceso de procesos que actúen con permisos suficientes en el equipo.

El contenido recuperado puede aparecer en el contexto de la conversación, historiales, resultados de herramientas y archivos producidos durante una tarea. No debe suponerse que todo se elimina al terminar una respuesta.

5. Conservación y eliminación

No se ha establecido una purga automática específica para esta integración. Las credenciales se conservan mientras el titular mantenga la conexión. Los historiales y los archivos derivados siguen las opciones de conservación de Hermes y las decisiones de eliminación del titular; las copias que puedan conservar los proveedores se rigen por sus propias condiciones.

El titular puede revocar el acceso desde las conexiones de su cuenta de Google y solicitar la retirada de las credenciales locales y de los historiales o archivos derivados que identifique. Revocar el acceso impide el acceso futuro, pero no borra automáticamente copias de datos ya obtenidas. Eliminar datos locales tampoco elimina los originales de Google.

6. Esta web

El código de estas páginas no incluye analítica, publicidad, cookies propias, formularios, JavaScript ni recursos de terceros. Las páginas se alojan en GitHub Pages, en https://puppetpaper.github.io/agente-google-info/. GitHub registra y conserva la dirección IP de quienes visitan sus páginas para fines de seguridad, aunque no hayan iniciado sesión. Consulta la declaración de privacidad de GitHub. La información de Google y las credenciales OAuth no se alojan en este sitio.

7. Uso limitado y cambios

El acceso y uso de datos de Google están sujetos a la Política de Datos de Usuario de los Servicios API de Google, incluidos sus requisitos de Uso Limitado. Publicar esta política no certifica que Google haya verificado la aplicación ni que haya aprobado su arquitectura.

El titular revisará esta información si cambian los servicios, proveedores o finalidades de la integración. Debe revisar este documento y sus condiciones reales antes de adoptarlo como política pública.
